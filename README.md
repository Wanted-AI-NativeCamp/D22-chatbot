# D22-RAG · 클래스로 마켓 문서 질문 앱

문서(`docs/*.md`)를 조각으로 자르고, 숫자 벡터로 바꿔 저장한 뒤,
질문과 비슷한 조각을 찾아 **그 내용으로만** 답하는 RAG 실습 프로젝트예요.

> `docs/`의 문서는 수업용 가상 문서예요. 클래스로 마켓은 연습용 가짜 회사입니다.

## RAG 4단계

| 단계 | 하는 일 | 파일 |
|---|---|---|
| 1. 자르기 | 문서를 400자 안팎 조각으로 자름 (출처 = 파일 이름) | `rag.py` `split_docs` |
| 2. 임베딩 | 조각을 숫자 벡터로 바꿔 `index.json`에 저장 | `rag.py` `embed_texts`, `r3_index.py` |
| 3. 유사도 검색 | 질문도 벡터로 바꿔 가장 비슷한 조각 3개를 찾음 (코사인 유사도, 클수록 비슷) | `rag.py` `search` |
| 4. 답하기 | 찾은 조각만 자료로 넣어 모델이 답함. 출처는 코드가 붙임 | `rag.py` `build_messages`, `ask_model`, `add_sources` |

질문 하나에 OpenAI API를 2번 불러요 (임베딩 1번 + 답 만들기 1번).

## 파일 구성

```
D22-RAG/
├─ docs/                 문서 6개 (.md)
├─ rag.py                공통 함수 (읽기 · 자르기 · 임베딩 · 검색 · 답하기)
├─ r1_alone.py           문서 없이 모델에게 그냥 물어보기 (비교용)
├─ r2_split.py           조각 크기 100 · 400 · 1500 비교
├─ r3_index.py           임베딩해서 index.json 만들기
├─ r4_search.py          검색만 (답 없음)
├─ r5_answer.py          검색 → 프롬프트 → 모델 호출을 단계별로 보여 주며 답하기
├─ app.py                Flask 웹 앱
├─ templates/ask.html    웹 화면
├─ index.json            r3 실행 결과 (조각 + 벡터)
├─ requirements.txt
└─ .env                  API 키 (Git에 올리지 않음)
```

## 준비

1. 패키지 설치
   ```
   pip install -r requirements.txt
   ```
2. `.env` 만들기
   ```
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=사용할 채팅 모델 이름
   OPENAI_EMBEDDING_MODEL=text-embedding-3-small
   ```
   `OPENAI_EMBEDDING_MODEL`은 생략하면 `text-embedding-3-small`을 써요.
3. 인덱스 만들기 (처음 한 번, 문서를 바꾸면 다시)
   ```
   python -X utf8 r3_index.py
   ```

Windows 콘솔에서 한글이 깨지면 `python -X utf8 ...`로 실행하세요.

## 실행

| 하고 싶은 것 | 명령 |
|---|---|
| 웹 앱 | `python -X utf8 app.py` → http://127.0.0.1:5000 |
| 단계별로 보며 답하기 | `python -X utf8 r5_answer.py "수업 3일 전에 취소하면 얼마 돌려받아?"` |
| 검색만 | `python -X utf8 r4_search.py "고객센터 전화번호가 뭐야"` |
| 조각 크기 비교 | `python -X utf8 r2_split.py` |
| 문서 없이 물어보기 | `python -X utf8 r1_alone.py` |

## 웹 앱 규칙

- 질문은 300자까지예요. 넘으면 안내 문장과 함께 입력 화면으로 돌아가요 (쓴 글은 그대로 남아요).
- `index.json`은 앱이 켜질 때 한 번만 읽어요. 문서나 인덱스를 바꾸면 앱을 껐다 켜세요.
- 답과 함께 찾아온 조각 3개의 파일 이름 · 점수 · 앞부분 150글자를 보여 줘요.

## 답하기 규칙 (프롬프트)

1. 자료 안에 있는 내용만으로 답한다. 원래 알던 지식은 쓰지 않는다.
2. 자료에 없으면 "문서에서 찾지 못했어요."만 답한다.
3. 숫자 · 기간 · 조건은 자료에 적힌 그대로 쓴다.
4. 출처는 모델이 쓰지 않는다. 코드가 검색된 조각의 파일 이름을 붙인다.
   (답이 "찾지 못했어요."이면 붙이지 않는다.)

## 알아둘 점

- **출처 목록은 "찾아온 조각의 파일"이에요.** 답에 실제로 쓰이지 않은 조각의 파일도 포함될 수 있어요.
- **temperature는 지정하지 않아요.** 사용 중인 모델이 0을 지원하지 않아서 기본값을 써요. 같은 질문도 표현이 조금씩 달라질 수 있어요.
- **조각은 겹치지 않게(오버랩 0) 잘라요.** `r3_index.py`의 `CHUNK_OVERLAP`으로 바꿀 수 있어요.
- 문서에 없는 질문(예: 전화번호)에는 "문서에서 찾지 못했어요."가 나와야 해요.
